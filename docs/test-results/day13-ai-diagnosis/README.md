# Day13 AI失败诊断效果评测

## Baseline v1

v1完成了字段级答案泄漏检查，但部分诊断标题包含已知根因，例如“Broker存储挂载丢失”和“ThreadLocal未清理”。

自动指标：

- Schema通过率：100%
- 故障层级准确率：80%
- 根因标签精确匹配率：0%
- 完全匹配率：0%
- 证据关键词平均召回率：35%

人工评审：

- 完全正确：0
- 部分正确：4
- 证据不足：1
- 综合评分：16/30，53.33%

## Baseline v2

v2新增diagnosis_title，仅向模型提供中性故障现象，并通过字段级和语义级答案泄漏检查。

自动指标：

- Schema通过率：100%
- 故障层级准确率：60%
- 根因标签精确匹配率：0%
- 完全匹配率：0%
- 证据关键词平均召回率：28.33%

## 结论

v2去除标题中的根因信息后，故障层级准确率和证据召回率下降，说明v1受到语义泄漏影响。v2作为后续模型、Prompt和诊断证据优化的正式基线。

当前评测样本只有5条，指标只用于项目内基线比较，不代表模型在通用故障诊断任务上的总体准确率。
